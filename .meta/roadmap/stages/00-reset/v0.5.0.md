# version: v0.5.0
status: planned

## Goals
- Roadmap epic 0.4: the first public release, of `inkfold` on PyPI, through trusted publishing
  (owner's decision, 2026-10-29): a GitHub Actions workflow publishes on a version tag, with no
  token stored anywhere.
- A versioning and deprecation policy, and a changelog.

## Objectives / acceptance
- A workflow builds the wheel and sdist, runs the existing artefact checks, and publishes on a
  version tag through PyPI's trusted publishing (`id-token: write`); no secret is configured.
- The workflow matches the pending trusted publisher the owner registered on PyPI on 2026-11-09:
  project `inkfold`, owner `RorySullivan1`, repository `inkfold`, workflow file `release.yml`,
  environment `pypi`. A mismatch in any one fails the upload.
- `pip install inkfold` from PyPI in a clean venv renders an email.
- The library ships under MIT, and the README states that the render service and any hosted
  product are licensed separately (open core).
- `CHANGELOG.md` exists in Keep a Changelog form, and the deprecation policy says how long a
  public name survives once deprecated.
